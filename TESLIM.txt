PAKET İÇERİĞİ
- backend/     Node.js + Express + MongoDB + Socket.io (API, anomali motoru)
- mobile/      React Native (Expo) mobil uygulama
- dashboard/   React web paneli (canlı grafik, harita, alarmlar)
- docs/        API dokümantasyonu, kurulum kılavuzu, sistem mimarisi,
               veri modeli, sunum notları, demo videosu rehberi
- sunum/       Proje raporu (.docx + .pdf) ve sunum (.pptx + .pdf)
- KURULUM.md   Sıfırdan (yeni bilgisayarda) kurulum adımları
- README.md    Genel bilgi ve hızlı başlangıç

ÇALIŞTIRMA (özet)
1. Node.js ve MongoDB kurulu olmalı (MongoDB servis olarak çalışır durumda).
2. kurulum.bat  -> bağımlılıkları kurar, .env oluşturur, örnek veriyi yükler (tek seferlik).
3. baslat.bat   -> backend + web paneli + simülatörü başlatır, tarayıcıda açar.
   (Ayrıntılı adımlar ve telefon ile canlı demo: KURULUM.md ve docs/ klasörü)

NOT: Bu pakette node_modules yer almaz; "npm install" (veya kurulum.bat) ile kurulur.
